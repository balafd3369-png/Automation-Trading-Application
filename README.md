# Trade with Beast

Cursor-style **pressure board** for Indian markets — zone lines (B2, B1, S, S1, S2), buying/selling/range rails, Lightweight Charts, and optional **m.Stock** live quotes.

**No auto-orders.** Read-only board and charts in this phase.
